# Image Studio V51 — T-Shirt Production Suite

V28 builds on V27 and connects the Smart Artwork Library directly to the Production Queue.

## New
- Direct "Send Selected to Queue" handoff.
- Drag & drop artwork into Production Queue.
- Dark Garment 6-Color, Light Garment CMYK, Production Proof and Fast Preview presets.
- Apply preset to selected queue jobs or all jobs.
- Save/load queue JSON.
- Save/load reusable production templates.
- Basic per-job print-size/DPI estimation helper.

## Important
This remains a desktop engineering/production workflow. Color separation and halftone outputs are approximations unless calibrated to the actual RIP, inks, mesh, exposure and substrate. It is not a calibrated ICC/RIP replacement.

Run with Python + dependencies from requirements.txt.


## V29
Unified Production Workspace with visual job thumbnails, per-job editor, presets, validation, workspace save/load, direct queue handoff, and selected/all job execution.

## V31
Adds Print Production Intelligence: measurable print-size/DPI checks, artwork coverage, gang-sheet utilization estimate, garment proof, registration preview, warnings, and production intelligence JSON report. These are engineering/preview tools, not calibrated RIP/ICC results.
