# Image Studio V21

Added:
- Print Sheet / Gang Sheet tab
- A4, A3, 12x18in and 13x19in presets at 300 DPI
- Multiple copies with configurable sheet size, gap and margin
- Optional 90-degree artwork rotation
- Corner and per-artwork registration marks
- Copy labels
- Multi-page packing when copies exceed one sheet
- Layout manifest JSON
- PNG print-sheet export with DPI metadata

Important: this is a deterministic geometric layout utility. It is not a calibrated RIP, ICC proofing engine, or automatic true-shape nesting system.
