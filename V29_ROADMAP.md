# V29 — Unified Production Workspace

## Added
- Visual job list with thumbnails.
- Unified per-job editor for source, separation, DPI, cleanup, reconstruction, underbase and halftone options.
- Built-in production presets including Dark Garment 8-Color Pro, Film Preview and High Quality Light.
- Add, duplicate, remove and reorder jobs.
- Save/load workspace JSON.
- Save current job options as a reusable custom preset JSON.
- Per-job preflight validation.
- Send entire workspace directly to the existing Production Queue.
- Run selected job or the full workspace from the unified tab.
- Pause/resume/cancel with background worker.
- Live job result table and production log path.
- Source existence and estimated workload summary.

## Accuracy notes
- Preflight validates measurable image/file properties; it is not a calibrated RIP proof.
- Existing separation/halftone/reconstruction operations remain the project's engineering/preview implementations where noted in earlier roadmaps.
- AI functions remain optional and dependency-dependent.
