# V54 — Smart Project & Workspace Manager

V54 adds a local project registry for organizing client/order/job-linked project folders without deleting source files.

Features:
- project registry with search
- project/client/order/job metadata
- folder statistics
- open project folder
- archive project folder with SHA-256 manifest
- JSON registry export
- safe record removal (does not delete project files)
- self-test and compile validation

This is a local workspace organizer; it does not replace the V41 version archive or V42 job database.
